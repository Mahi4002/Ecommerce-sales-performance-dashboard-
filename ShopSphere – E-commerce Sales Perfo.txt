 ShopSphere – E-commerce Sales Performance Dashboard

1. Project Overview

This project focuses on analyzing e-commerce sales data and developing an interactive dashboard using Microsoft Power BI. The purpose is to understand sales performance, identify top-performing product categories, compare regional sales, and monitor order and payment patterns.

The project follows a data analysis workflow, including data cleaning, data preparation, KPI calculation, data visualization, and business performance analysis.

2. Project Objectives

- Analyze overall sales and profit performance.
- Identify the best-performing product categories and products.
- Compare revenue across different states.
- Understand order status distribution.
- Analyze customer payment method preferences.
- Create an interactive dashboard to support data-driven decision-making.

3. Tools and Technologies

- Microsoft Excel: Data inspection and cleaning.
- Microsoft Power BI: Dashboard development and visualization.
- Power Query: Data transformation and preparation, where applicable.
- DAX: KPI and measure calculations in Power BI.

4. Dataset Description

The dataset contains e-commerce order-line information, including:

- Order ID and Order Date
- Customer ID
- Product ID and Product Name
- Category
- Quantity, Unit Price and Discount
- Unit Cost
- City and State
- Payment Method
- Order Status

The dataset is used for portfolio and learning purposes.

5. Data Cleaning and Preparation

The data preparation process includes:

- Checking missing values and duplicate records.
- Identifying invalid quantities and prices.
- Standardizing category and order status values.
- Handling missing values using documented rules.
- Preparing date and numeric columns for analysis.
- Creating calculated fields for sales, cost and profit.

6. Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- Total Revenue: Total net sales generated.
- Total Orders: Number of distinct orders.
- Total Profit: Revenue after deducting the calculated product cost.
- Average Order Value (AOV): Total revenue divided by the number of distinct orders.

The exact calculation rules and treatment of cancelled or returned orders should be documented based on the final report measures.

7. Dashboard Features

The dashboard contains:

1. Monthly Revenue Trend
2. Revenue by Category
3. Order Status Breakdown
4. Top 10 Products by Revenue
5. Revenue by State
6. Payment Methods Distribution

Interactive slicers are provided for Date Range, Category, State and Payment Method.

8. Project Folder Structure

- `Raw_Data` – Original dataset.
- `Cleaned_Data` – Cleaned dataset used for analysis.
- `PowerBI` – Power BI report file.
- `Screenshots` – Dashboard screenshots.
- `Project_Documentation` – Project notes and documentation.

9. Business Questions

This dashboard is designed to answer questions such as:

- How does revenue change over time?
- Which product categories generate the most revenue?
- Which products contribute the most to sales?
- Which states generate the highest revenue?
- What proportion of orders are completed, cancelled or returned?
- Which payment methods are used most frequently?
