## 📌 Project Overview

ShopSphere is an interactive e-commerce sales performance dashboard built using Microsoft Power BI. It provides a consolidated view of sales, orders, profitability, product performance, regional sales, order status, and payment methods.

The goal of this project is to demonstrate how raw e-commerce data can be transformed into a clean, interactive dashboard that helps business stakeholders monitor performance and make data-informed decisions.

## 🎯 Business Objectives

- Monitor overall revenue, profit, order volume, and average order value.
- Identify top-performing product categories and products.
- Compare sales performance across states.
- Understand the distribution of completed, cancelled, and returned orders.
- Analyze customer payment method preferences.
- Enable interactive analysis using date, category, state, and payment filters.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** — Dashboard development and visualization
- **Power Query / Excel** — Data preparation and cleaning
- **DAX** — Measures and business calculations
- **GitHub** — Project documentation and version control

## 📊 Dashboard Features

### 1. KPI Cards
- Total Revenue
- Total Orders
- Total Profit
- Average Order Value (AOV)

### 2. Monthly Revenue Trend
Visualizes monthly revenue performance to help identify changes and patterns over time.

### 3. Revenue by Category
Compares revenue across product categories to identify major contributors to sales.

### 4. Order Status Analysis
Displays the distribution of completed, cancelled, and returned orders.

### 5. Top 10 Products by Revenue
Highlights the products generating the highest revenue.

### 6. Revenue by State
Compares sales performance across different states.

### 7. Payment Method Analysis
Shows how orders are distributed across payment methods, including UPI, credit cards, debit cards, cash on delivery, and net banking.

### 8. Interactive Slicers
Users can filter the dashboard by:
- Date range
- Product category
- State
- Payment method

## 📈 Key Business Questions

This dashboard helps answer questions such as:

- How much revenue and profit did the store generate?
- Which product categories contribute the most revenue?
- Which products are the top revenue generators?
- Which states generate the highest sales?
- What proportion of orders are completed, cancelled, or returned?
- Which payment methods are most commonly used?
- How does revenue change over time?

## 🧹 Data Preparation

The project dataset was prepared for analysis by checking data quality, handling missing values, standardizing inconsistent category and order-status values, identifying duplicate records, and reviewing invalid quantities and prices.

Calculated fields such as net sales, total cost, and profit were used for business analysis.

**Note:** This is a practice portfolio project using a sample dataset, not actual company sales data.
